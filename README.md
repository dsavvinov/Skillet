# Skillet - Fork for WoW Synastria

This is a fork of the original [Skillet](https://github.com/b-morgan/Skillet) World of Warcraft addon, adapter for Synastria private server. 

Changes:
- Support filtering items by their attuned/forged state
- Show attunement/forging state of an item in crafting window
- Support of reagent bank
- Use default game tooltip in Skillet window (allows to pick up other extensions, like attunement state)
- Add a panel with all professions to the Skillet window (semi-backported from later Skillet versions)
- Couple of cosmetical tweaks
  - Show required item lvl of a recipe as `(L\<number\>)`, e.g. `(L42)` instead of `[42]` as that was very confusing due to classic Blizzard's crafting UI using number in square brackets for amount of craftable items
  - Remove green gradient background from the title bar (opinionated, but doesn't hold in 2025)
